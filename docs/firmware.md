# Firmware selection and updates

Match firmware to the exact camera model and hardware revision. Review the
release notes, use an authorized source, and verify the package with a
vendor-published checksum when one is available. Follow the camera's upgrade
procedure and keep power stable throughout the update. Preserve a configuration
backup before changing firmware.

Raw flash partition images are not vendor update packages and are not suitable
for upload through the camera upgrade page. Store recovery files and camera
configuration backups in access-controlled storage.

The following versions provide known compatibility baselines for the guides:

| Camera | Firmware baseline |
|---|---|
| CIVS-IPC-2621V | V4.4.2-2 |
| CIVS-IPC-6000P | 2.5.0-10 |
| CIVS-IPC-6400E | 2.0.3-27 |

Firmware and behavior can vary by hardware revision. Do not downgrade solely to
match a version in this table; confirm compatibility with the camera's release
notes first.
